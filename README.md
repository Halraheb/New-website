# تحصيلي فيزياء 2 — مدرسة الخويلدية الثانوية

موقع اختبار ومسابقات فيزياء 2 (إعداد الأستاذ حسن الراهب)، مع حسابات للطلاب وقاعدة بيانات PostgreSQL على **Railway**.

## المزايا
- **حسابات الطلاب**: إنشاء حساب ودخول (كلمات المرور مشفّرة). الصلاحيات: طالب · معلم · مدير النظام.
- **الاختبار**: 85 سؤالاً مع شرح الحل في ست وحدات، بوضعين: مسابقة فرق داخل الفصل، ولعب فردي تُحفظ نتيجته في حساب الطالب مع كل إجابة.
- **ملف الطالب**: المستوى ونقاط الخبرة (XP)، 13 إنجازاً (برونزي/فضي/ذهبي) مع شريط تقدم،
  الإحصائيات، نقاط القوة والضعف في كل وحدة، الأسئلة الأكثر خطأً، تطور الدرجات، وآخر الاختبارات.
- **لوحة المعلم**: التحليلات (للمدرسة، أو مرحلة، أو طالب)، سجل الطلاب اليدوي (الدرجة ومستوى التقدم)،
  كل الدرجات مع تصدير CSV، إدارة المستخدمين، و«السجل القديم» لنتائج ما قبل الحسابات.
- وضع فاتح وداكن.

## بنية المشروع
```
backend/            الخادم (Node.js + Express): واجهة JSON تحت /api
  server.js         نقطة التشغيل
  db.js             الاتصال بقاعدة البيانات وإنشاء الجداول تلقائياً
  lib.js            الجلسات والصلاحيات والوحدات
  achievements.js   الإنجازات والمستويات
  routes/           auth · results · users · students · analytics
frontend/           الواجهة
  index.html        الاختبار (فرق / فردي)
  profile.html      ملف الطالب
  dashboard.html    لوحة المعلم
  login.html        الدخول وإنشاء الحساب
  questions.js      بنك الأسئلة وشروحها
  common.js · shell.css · style.css · analytics.js
```

## قاعدة البيانات
تُنشأ الجداول تلقائياً في مخطط (schema) خاص اسمه `physics`، فلا تتعارض مع جداول أي موقع آخر يستخدم القاعدة نفسها:
`users`, `results`, `answers`, `achievements`, `students`.
الجداول القديمة `visits` و`attempts` (في `public`) تبقى كما هي، وتظهر المحاولات القديمة في «السجل القديم».

## المتغيرات في Railway
| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `ADMIN_USERNAME` | `admin` (اختياري) |
| `ADMIN_PASSWORD` | كلمة مرور المدير، تُحدَّث عند كل تشغيل |
| `JWT_SECRET` | نص عشوائي طويل (حتى لا يُطلب الدخول بعد كل إعادة تشغيل) |
| `NODE_ENV` | `production` |

يُبنى الموقع على Railway من `Dockerfile` (Node 22). لوحة المعلم: `/dashboard.html` (الرابط القديم `/admin` يحوّل إليها).

## التشغيل محلياً
```bash
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/physics ADMIN_PASSWORD=admin123 JWT_SECRET=dev npm start
# http://localhost:3000
```
